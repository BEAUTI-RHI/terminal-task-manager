 # Terminal To-Do List

  Domain: Productivity / CLI

  ### Mini PRD

  Build a terminal task manager where users can create, complete, delete, and
  search tasks.

  ### Requirements

  The application must:

  • Create tasks with a title and priority.
  • Assign each task a status such as pending or complete.
  • List all tasks.
  • Mark a task as complete.
  • Delete a task.
  • Search tasks by title.
  • Prevent operations on invalid task IDs.

  ### Constraints

  • Reuse your menu-driven CLI approach from Project 1.
  • Store tasks in a  std::vector .
  • Give every task an ID.
  • Use a dedicated task type such as  struct Task .

  ### Stretch Features

  • Due dates.
  • Sort by priority.
  • Show only incomplete tasks.
  • Add tags such as  work ,  study , or  personal .

  ### Learning Goal

  You will learn how to:

  • Model real-world data with structs/classes.
  • Work with collections of objects.
  • Search and modify vector contents.
  • Design reusable functions.
  • Separate user interaction from application logic.
  • Think about object state and lifecycle.
